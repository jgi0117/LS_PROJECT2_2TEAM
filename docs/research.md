# 리서치 통합본: 기상청 API 기반 주제 후보 5개

작성일 2026-10-22. 팀원 3명이 따로 쓴 리서치 파일 3개를 한 파일로 합치고, 모든 출처를 Claude가 실제로 열어 대조한 결과를 반영했다.

> **읽는 법**
> - 합친 파일: `research.md`(전성은, 주제 1), `research (1).md`(주제 2), `research.md.md`(ChatGPT 개인 초안, 주제 3~5).
> - 표의 "직접 열어 봤나"는 **Claude가 해당 출처를 열어 본문과 대조했다**는 뜻이다. 대조 결과 맞으면 "확인", 틀린 곳은 고쳐서 "확인(수정)"으로 적었다.
> - 열 수 없었거나 출처에서 근거를 찾지 못한 내용은 **표에서 삭제**했고, 삭제 목록을 맨 아래에 적었다.
> - 교안은 팀원이 직접 열어 보는 것을 요구한다. 아래 내용은 **팀원이 한 번 더 열어 보며 확인**하면 더 좋다. 특히 수치와 법령 문구는 원문 대조를 권한다.
> - 사실(출처에서 읽음)과 해석(Claude 생각)은 구분했고, 해석은 "(해석)"으로 표시했다.

### 2. 추측 (출처 없음, 인터뷰로 확인)

- 생산·구매 담당은 날씨 앱과 지난해 판매 엑셀을 보고 감으로 생산량을 정할 것이다.
- 단기예보(글피까지)만으로는 생산계획(주~월 단위)에 부족해서 중기예보나 계절 전망이 필요할 것이다.
- 중소 제조사는 풀무원처럼 기상 데이터 분석을 따로 맡길 여력이 없을 것이다.
- 환율이 오르는 달에는 수입 원료 발주 시점을 정하는 일이 날씨 판단과 함께 부담이 될 것이다.

### 한계

- 현업자 직접 증언과 팀원 직접 검색 결과가 없다. 문제의 실재는 피해 수치와 정부 발표에 기대고 있다.
- 법령 조문은 법제처 페이지의 요약본을 거쳐 읽었다. 별표 13의2(체감온도 측정)와 개인정보보호법은 열어 보지 못했다. 법령 문구는 법제처 원문과 한 번 더 대조하면 좋다.
- 지상관측 API의 명세와 분당 한도, 과거 자료 범위, 출처 표기법은 열어 보지 못했다. 실제 호출도 해 보지 않았다.
