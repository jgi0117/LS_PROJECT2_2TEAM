# 리서치 통합본: 기상청 API 기반 주제 후보 5개

작성일 2026-10-22. 팀원 3명이 따로 쓴 리서치 파일 3개를 한 파일로 합쳤다. **원문 표와 문장은 그대로 옮겼고, 아래 "읽는 법"과 "한눈에 보기", 공통 절만 새로 썼다.** 원본 3개와 `docs/research.md`는 건드리지 않았다.

> **읽는 법**
> - 합친 파일 3개와 쓴 방법
>   - `research.md` (전성은, Claude 웹 조사): 주제 1. 대부분 검색 결과 발췌만 본 상태라 "직접 열어 봤나"가 미확인이다.
>   - `research (1).md` (Claude 웹 조사+페이지 열기): 주제 2. 기사 3건과 API허브 이용안내는 Claude가 열어 봤다.
>   - `research.md.md` (**ChatGPT가 쓴 개인 조사 초안**): 주제 3~5. 파일 안에 팀 공통 절차(직접 검색, Claude 조사, 출처 확인)를 아직 안 했다고 적혀 있다. 출처 링크를 열어 봤는지 알 수 없으므로 **모두 미확인으로 표시했다.**
> - 모든 줄은 **팀원이 직접 열어 보기 전까지 교안 기준으로 확인 전**이다.
> - 주제 3~5의 "찾은 사람"과 "직접 열어 봤나", "인터뷰에서 확인할 것" 칸은 원문에 없어 통합하면서 채웠다. 확인할 것 칸은 원문의 문제 가설과 제약을 바탕으로 한 정리이며 "(통합 시 정리)"로 표시했다.

- 생산·구매 담당은 날씨 앱과 지난해 판매 엑셀을 보고 감으로 생산량을 정할 것이다.
- 단기예보(이틀 뒤까지)만으로는 생산계획(주~월 단위)에 부족해서 중기예보나 계절 전망이 필요할 것이다.
- 중소 제조사는 풀무원처럼 기상 데이터 분석을 따로 맡길 여력이 없을 것이다.
- 환율이 오르는 달에는 수입 원료 발주 시점을 정하는 일이 날씨 판단과 함께 부담이 될 것이다.

### 3. 인터뷰에서 확인할 것

1. 가장 최근 폭염이나 장마로 생산량·발주를 바꿨던 날을 처음부터 이야기해 주세요.
2. 그때 날씨는 어디서 확인했고, 며칠 앞까지 보고 결정했나요?
3. 재고가 남거나 모자랐던 최근 사례와 그 손실은 얼마였나요?
4. 제품별로 몇 도부터 판매가 늘기 시작하는지 알고 있나요? 어떻게 알게 됐나요?
5. 원료는 수입 비중이 어느 정도이고, 환율 변동 때 발주를 어떻게 하나요?
6. 날씨 예보를 바탕으로 생산을 바꿀 때 누구의 승인을 받고, 어떤 순서로 처리하나요? (요청 흐름 재료)

### 4. 한계

- 편의점 매출 기사는 유통 쪽 수치라 제조사 출고량·생산 문제와 다르다. 제조사 관점에서 2026년 날씨가 생산·재고에 준 영향을 다룬 한국 기사는 이번에도 찾지 못했다. 제조사 IR 자료나 3분기 실적 발표를 직접 찾아야 한다.
- 장마·냉하의 매출 영향은 2020년 사례만 확인했다. 최신 사례와 재고 부담을 직접 다룬 기사는 없다.
- 식품위생법 조문과 제조사의 재고 폐기 손실 처리 방식은 확인하지 못했다.
- 임계 온도와 1도당 증가율은 2013년 편의점 자료와 비엄밀한 추정이라 근거가 약하다.
- 기상청 API의 정확한 서비스 이름, 호출 한도, 항목 코드는 포털에서 직접 확인해야 한다.

### 인터뷰에서 확인할 것

### 한계

- 현업자 직접 증언과 팀원 직접 검색 결과가 없다. 문제의 실재는 피해 수치와 정부 발표에 기대고 있다.
